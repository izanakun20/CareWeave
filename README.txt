DATATHON STARTER DATA PACK
Four balanced, multi-table synthetic datasets for product-building tracks.
All records are synthetic and intended for a student hackathon prototype. They are not real hospital, campus, municipal, or company records. Do not use them for actual clinical, public-safety, or financial decisions.
Each track includes multiple related CSVs and a README with joins and caveats. Teams should profile the data, clean it, engineer useful features, train/evaluate models where appropriate, and build a usable product.
The dataset is a foundation, not a complete answer. Teams may add external data/APIs if permitted, but must still use the provided data meaningfully and disclose sources.
